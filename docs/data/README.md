# 事件制作数据

[events-production-v1.0.json](events-production-v1.0.json) 是《游戏进程与事件策划案》的结构化制作底稿，状态为 `design-not-implemented`。

- cards：46张关键事件卡，含44个场景和2个拆分节点；每卡2～4个选项。
- echoes：10条多年因果链，记录起因、跨度、条件和实际影响。
- macro：8类宏观背景。
- 50条日常素材当前在策划源文档中，未伪装成已导出的JSON运行事件。

此文件不能直接替换当前引擎的事件模块。正式开发时还需确定效果结构、单位、触发条件、版本与测试，并同步源文档。
