v0.4 · 新方向整合稿｜2026 年 10 月 30 日｜本稿仅用于设计讨论，未修改站点

主要依据：用户提供的《人生模拟游戏 · 游戏内容设计文档》v0.3。对照材料：当前《如果你是ta》站点的角色、事件、理财、婚育、存档和部署实现。本稿以新文档的理念为准，旧版本仅作为可复用资产，不再沿用旧版称号和成年身份开局。

阅读标记：【方向确定】指上传文档明确提出的方向；【整理建议】指为衔接玩法而补充的默认方案，尚未实现；【待定参数】指需要原型与测试再确定的数字。没有把“建议”写成已上线功能。

建议先阅读第一章的方向变化与第十五章的建议默认值；按年龄查看内容时读附录 A，日常素材在附录 B，旧站点内容迁移索引在附录 C。

# 一、这次调整的结论

这是一款从记事时开始的文字人生模拟。玩家面对的是自己这一生能做的选择，而不是把数值刷到最高。出身影响资源和机会；选择改变路径；时代改变环境。人生结束时，游戏只呈现发生过什么，不替玩家评价这一生。

| 维度 | 当前站点 | 新方向 |
| --- | --- | --- |
| 起点 | 随机成年职业，22～45 岁开局 | 约 5～6 岁开始；三个文字出身中选择一个 |
| 职业 | 开局抽取 12 种身份 | 职业由教育、所在地、经验与机会逐步形成 |
| 时间 | 固定 2026—2076，最长 50 年 | 按年龄走过童年、少年、青年、中年、老年，不固定五十年 |
| 状态 | 技能、压力等较多数字常显 | 健康、心情、金钱、关系、能力、声誉六类；压力与因果在后台 |
| 重要关系 | 主要是伴侣与一名孩子 | 家人、朋友、伴侣及其相遇、联系、分开与离世 |
| 事件 | 83 个成人生活／职业／家庭事件 | 按阶段组织；重视每条已选路径的长期回响 |
| 结局 | 称号、生活标签、成就高点 | 人生回顾，不设称号、综合评分、排名和遗憾清单 |
| 重玩 | 抽身份、刷不同称号 | 重新经历一生，无属性、天赋和解锁继承 |
| 社群传播 | 分享称号与资产结果 | 分享真实经历、重要的人、时间分配和玩家自己的话 |

【方向确定】取消旧版“人间清醒”“搞钱狠人”等结局称号、成就收集与完成度表达；也不改成另一套带高低的 MBTI 标签。选择倾向可以描述，但不能用于评分或属性加成。

# 二、体验目标与写作底线

- 时间流逝：日常一条条经过，几年之后，原先的处境已经变了。

- 取舍：一项选择可能得到时间、收入或陪伴，也改变其他安排；不存在每个方面都占优的常驻选项。

- 回响：只让玩家已经选择的那条路继续生长，不展示没有走过的另一条路。

- 差异：资源差距保留，不把清贫写成天然淳朴，也不把富裕写成必然空虚。

- 不替玩家定性：旁白陈述事实，人物可以表达自己的感受；角色的主观感受不是系统的最终判词。

“不评判”不等于没有后果。借款产生偿付义务，法律相关行为可能产生相应社会后果，关系中的另一方也有自己的反应。需要移除的是旁白的道德标签和全局分数，而不是让所有决定都没有影响。

“每条路各有得失”是事件与长期系统的要求，不是每一次送礼、陪伴、喝水都必须附送一个负面数值。低成本行动也消耗时间和机会，但不为了平衡而凭空制造事故。极端灾害与亲人离世也不需要被写成“总有好处”。

| 避免 | 采用 |
| --- | --- |
| 你明智地选择了稳定工作 | 你接受了那份固定排班的工作。 |
| 创业失败，血本无归 | 第三年，公司关闭，账上剩余的资金用于支付欠款。 |
| 你错过了去外地的机会 | 你留在了本地，搬回离家近的住处。 |
| 独身让你缺少完整的家庭 | 你一个人生活，周末常和两位朋友见面。 |
| 要是当年坚持爱好就好了 | 你在整理旧物时，找到了那本画册。 |

# 三、一局人生如何开始

## 3.1 三选一的出身

【方向确定】每局生成三个互不重复的起点，至少涉及两档资源条件。玩家只能看到生活描写，不看到资源档、加成、稀有度、优劣排序。选中后，另外两张从当前人生中消失，不能回看或重抽。

【整理建议】本次人生的三个候选在进入开局页时就按世界种子确定并保存，刷新不会换一组。返回首页或关闭弹窗也不重新抽取。完成当前起点选择后才进入故事；新开一局可以重新生成整个人生，这不属于当前人生的重抽。

| 起点 | 玩家看到的生活描写 | 策划资源参考，不展示 | 独有内容 |
| --- | --- | --- | --- |
| 老街坊里的家 | 你家在一条老街上，邻居都认识你。傍晚有人在门口摆小桌，吃的东西偶尔也会送到你家。 | 中低、较稳定 | 熟人网络、邻里往来、边界与议论 |
| 小店里的家 | 父母开着一家小店。你放学后坐在柜台边写作业，有人来买东西，也有人只是来聊几句。 | 中等、有波动 | 柜台见闻、帮忙、营业与陪伴时间 |
| 稳定工作的家 | 家里有固定的作息。饭后有人问起学校的事，书桌旁贴着新学期的安排。 | 中上、较稳定 | 明确的教育安排、家庭期待与自主选择 |
| 大城市的双薪家庭 | 你住在城市的一套公寓里。父母出门很早，周末的日历上写着几项课程和活动。 | 较高 | 课程与城市机会、接送与陪伴安排 |
| 务农的家 | 家里种着地。季节不同，饭桌上谈的事情也不同。天还没亮，有时就有人出门了。 | 较低、随收成变化 | 季节、农忙、地理距离与外出求学 |
| 祖辈带大的家 | 你跟祖辈住在一起。父母在外地工作，电话里常问你吃得怎样，回来的日子会提前写在日历上。 | 低到中、汇款支持 | 祖辈相处、远距离亲情、重逢与照护 |
| 常搬家的家 | 箱子还留在墙角。你去过不同的学校，到了新的地方，总要先记住回家的路。 | 中等 | 迁移、适应、旧友联系与新关系 |
| 生意起伏的家 | 家里做着一门生意。有时晚饭很热闹，有时大家一边吃，一边核对几张账单。 | 中到高、起伏较大 | 家庭经营变化、消费习惯、风险记忆 |

【整理建议】抽取实现：先抽一档资源条件，再抽另一档，最后抽第三个不重复的起点，并随机打乱显示顺序。资源条件是抽取约束，不是出身高低榜。资源跨度较大的起点，先确定本局家庭资源实例，再归入抽取用的资源档；同一出身可以有不同的具体条件。资源档仅用于生成候选，不在卡片上公开。具体权重为待定参数；不沿用旧职业概率。

## 3.2 姓名、年龄与时代

- 【沿用既有明确要求】姓名随机、不可编辑；【整理建议】出身、性格与兴趣潜质由种子确定，后续由选择形成经历。

- 【整理建议】首版统一 6 岁开场，覆盖上传文档约 5～6 岁的范围，避免为了年龄随机额外增加入学时间分支。首页主轴显示年龄，不再用固定“2026—2076”。

- 【整理建议】世界为中文语境的虚构社会，不预设现实国家、政策年份或历史事件。各局有不同经济与技术环境；相同世界种子可复现同一环境。

- 【整理建议】达到 100 岁可作为开发期的技术收束上限，最终年龄上限与自然健康曲线属于待定参数，不是寿命预测；多数人生可在此前因健康与事件自然结束。

## 3.3 成年前的钱从哪里来

【整理建议】把“个人的钱”与“家庭可承担的资源”分开。常驻金钱显示角色能支配的零用钱、储蓄与后来劳动所得；课程、学费、搬家等家庭开支，检查的是监护家庭预算与意愿，不直接要求六岁的角色承担成人贷款。

- 童年不把父母的房子、生意和借款计入角色个人净资产；资源宽裕的起点也不是把家庭财产全部转给孩子。

- 帮店里或田里做适龄小事，可改变亲情、见闻与零用钱；不作为儿童维持家庭经济的正式工作系统。

- 成年建立独立账户时，经过“离家／第一份收入／家庭支持”节点，明确收到多少钱、承担哪些自己的费用；不悄悄把家庭债务转成个人欠款。

- 旧版各职业的 −300～600 万等开局范围不直接搬到童年。成年后的经营借款、个人贷款和经营欠款，在对应实际事件发生时产生并说明。

# 四、状态、关系与选择取向

| 常驻状态 | 界面表达 | 系统用途 |
| --- | --- | --- |
| 健康 | 0～100，点开看身体近况 | 疾病、精力、年龄变化；终局的重要条件 |
| 心情 | 0～100，点开看近期变化 | 当前情绪状态，向性格基线逐步回归 |
| 金钱 | 可支配现金；详情列资产、负债、固定费用 | 消费、理财、教育与生活安排 |
| 关系 | 家人／朋友／伴侣三类摘要 | 各具体人物的联系与关系状态，不求一个总分 |
| 能力 | 0～100 的综合适应与学习能力 | 学习、工作、转型门槛；具体资格另记经历标记 |
| 声誉 | 0～100，提示当前相关圈子 | 职业和社群中的可见经历、机会；不等于道德或受欢迎总分 |

【整理建议】没有伴侣时显示“尚未开始伴侣关系”，而不是 0 分；亲人离世显示人物状态，不以一个红色扣分替代。家人、朋友、伴侣不平均成一个“人生关系得分”。童年声誉限定在学校与社区，不能用来直接解锁成年公共职位。

## 4.1 隐藏状态也要可感知

- 【方向确定】压力、出身／潜质、历史标记和随机性在后台运行；玩家不需要面对满屏参数。

- 【整理建议】压力数值隐藏，但通过“最近睡得浅”“工作消息不断”“有人帮你分担”等具体变化给出信号。严重压力事件之前至少有可观察的过程，不用隐藏数字突然扣除大量健康。

- 【整理建议】健康、情绪、技能与关系互相影响，但对持续低资源的惩罚设置上限和缓冲，避免一次事件让未来全部锁死。经济紧张仍有助学、职业学习、亲友协商、调整生活等不同走法。

- 【整理建议】能力高可以让信息更完整、复核更充分，不把投资结果变成必赚。压力高可以出现冲动操作的选择事件，不能未经玩家确认自动买入、借钱或卖出。

## 4.2 时间不是额外一条得分

【整理建议】后台按学习／工作、家人、朋友、兴趣、独处／休息和必要生活六类记录年度时间份额，总量有限。事件、职业、照护、通勤与生活重心分配这些时间；购买车辆或请人照护可以改变分配，不能凭空增加一年。回顾中的比例从这些记录累计，注明为游戏内估算，不临时编一张饼图。

## 4.3 选择取向

| 取向轴 | 回顾中的描述方式 |
| --- | --- |
| 偏安稳—偏变化 | “你多次保持现有安排”／“你在几个阶段改变了住处或方向” |
| 偏个人—偏关系 | 描述哪些安排围绕自己或重要的人，不写自私／无私 |
| 偏当下—偏长远 | 描述即时生活与长期准备，不写短视／明智 |
| 偏独立—偏借助他人 | 描述处理事情时的协作方式，不写强弱或依赖性格 |

取向不加属性、不分等级、不生成称号。只统计确实体现取向的选择；数据少时不强行归类。建议至少五次相关选择才描述某一轴，混合时写“有时……，也有时……”。这是待定参数，不使用带评判的雷达分数。

# 五、年龄阶段与职业形成

| 阶段 | 年龄参考 | 主要内容 | 该阶段的路径节点 |
| --- | --- | --- | --- |
| 记事期 | 6～12 | 家、学校、朋友、兴趣、小范围自主 | 入学后的适应、关系或独处、下一阶段学校 |
| 少年 | 13～18 | 学业、友情、早期感情、期待与自主 | 教育方向及阶段结束后的去向 |
| 青年 | 19～30 | 继续学习、第一份工作、城市与住处、恋爱 | 在自己路径上的独立生活与收入来源 |
| 中年 | 31～55 | 工作变化、照护、伴侣与孩子、居住、身体 | 职业与生活安排的阶段变化，不强制婚育 |
| 老年 | 56 岁以后 | 逐步退出工作、住处、支持网络、失去与回望 | 与当前工作相适应的退休／转变、生命收束 |

“必经”指有一次机会确认当前生活状态，不意味着每个人都必须上大学、恋爱、结婚、生孩子或当管理者。没有参加高中教育的人，不触发高中考试；没有子女的人，不触发家长会和与子女同住；经营者不触发被公司 HR 裁员。

## 5.1 教育路径不能预设只有一条

- 普通教育、职业学习、后续升学与成年后的再学习都形成各自完整的事件链；不把职业教育写成低等级结局。

- 【整理建议】约 15 岁的原稿“停止读书直接工作”调整为“转入职业训练／实作学习”，独立正式就业在适合年龄及虚构制度允许时开放。各路径仍可在后续重新学习。

- 【整理建议】18 岁五个选择拆成两步：外地学习／本地学习／进入工作路径／继续准备；选外地学习后，再讨论专业方向。毕业去向同样拆分城市选择与学习／备考方向，所有单次弹窗维持 2～4 项。

## 5.2 当前 12 个职业如何保留

| 现有内容 | 新位置 | 关键约束 |
| --- | --- | --- |
| 公司职员、技术工人、工程技术人员 | 求职、职业训练或转型后可能进入 | 岗位需符合教育、技能、经验与机会 |
| 医护、教师 | 对应学习与资格路径后的职业机会 | 没有资格时不能仅凭能力总值直接进入 |
| 自由职业者 | 兴趣、专业服务、积累客户后的工作方式 | 收入波动、沟通、时间与成本 |
| 小店店主、农场经营者 | 家庭接手、合作经营或成年创业 | 营业额、周转金、经营负债与个人现金分开 |
| 企业老板 | 已有经营进一步扩张的阶段 | 团队、回款、责任与个人生活都要有内容 |
| 社区工作者、政府职员 | 公共服务职业路径中的机会 | 权限来自当前岗位，离开后失效 |
| 市长 | 后续公共职责扩展内容，不是一期的随机开局 | 不能跳过任职经历和职责；不为了保留旧角色硬塞进所有人生 |

【整理建议】职业资格、在职状态、地点、排班和收入模型构成独立事实；所有职业事件同时检查这些事实，不能只看初始出身。离职、停业、退休和服刑应撤回权限与收入，再重新判断后续事件。

# 六、时间推进、事件窗口与界面

【方向确定】日常逐条滚动，关键事件 2～4 选项弹窗，选择时暂停；玩家作出选择后只沿已选路径继续。保留当前手机优先布局和已修正的事件窗口。

- 界面顺序：当前年龄与人物 → 精简状态 → 事件窗口 → 工作／学习、生活重心、关系、理财与消费入口。详情按需打开，不把多个大卡片排在事件前。

- 事件窗口刚开始按内容占用最小高度；达到手机／桌面的可视上限后，内部滚动。保留手动“下一件事”和速度切换。

- 打开信息面板不自动暂停。尚未提交的金额、消费和年度计划保留草稿；跨年时重新校验可用余额和资格，不能用旧界面提交过期条件。重大事件打断时保留草稿，处理后可返回。

- 重大选择已出现时暂停等待；关闭查看不代表自动选择。切到后台停止推进，回来不补跑几十年。

- 已读过往记录时保留滚动位置；新事件到来显示“有新记录”提示，点后回到顶部。人在最新记录处时保持新事件可见，不强行把正在读的旧事件顶走。此项是新建议，尚未实现。

## 6.1 建议的年度结算顺序

【整理建议】一年分为若干叙事段，但页面不展示复杂月份。顺序为：确认本年状态 → 呈现当年的环境变化 → 日常／必经节点／选择／回响 → 结算当年持续收入与开销 → 年度状态更新 → 下一年。不能先把整年财务与家庭结果算完，再允许玩家在中间作出看似影响当年的选择。

- 一次性消费与选择结果即时记账；工作、住处和照护安排从哪个年度生效必须写清。开发首版可统一“下一次年末结算生效”，不暗藏跨月追溯收费。

- 【整理建议】普通年可由 2～4 条日常和 0～1 个关键事件组成，阶段转换年允许额外节点；这是节奏参数，不强制每年弹窗。每阶段的主线节点是兜底，不能被随机池饿死。

- 成年后的全局上限按年龄推进，不再沿用旧版“50 年到 2076”判断；健康终局与最后一天应在同一个状态流程中处理。

# 七、事件与回响系统

| 类型 | 展示 | 作用 |
| --- | --- | --- |
| 日常 | 短句、自动发生、清楚显示状态变化 | 时间感、生活细节；不假装都是选择 |
| 关键 | 暂停，2～4 项选择 | 现实安排与取舍，写入已选事实 |
| 回响 | 满足时间和历史条件后出现，可能有选择 | 让已走的路多年后继续发生 |
| 宏观 | 从账单、学校、招聘、市场和生活里显现 | 改变同一世界的环境，不作为宏观操控面板 |

## 7.1 触发与调度

- 条件包括年龄／阶段、当前教育或职业、地点、人物是否仍在、关系状态、现金／家庭预算、资格、必须有／没有的标记、冷却时间和次数上限。

- 优先级建议：正在进行的选择 → 临近生命收束与必要生存节点 → 阶段必经节点 → 已排期回响 → 与当前角色相关的宏观反应 → 普通事件 → 日常填充。同年过多时顺延，不吞掉主线。

- 每次选项提交都重新检查条件，理由用“当前可用现金不足”“尚未具备相关资格”等事实表达，不只灰掉按钮，也不写“能力不够，不配选择”。至少保留一项当下能走的安排。

- 一次选择只产生一次后果和一次持久化记录；重载、点击两次或回放分享链接不能重复扣费、生育或记两次回响。

## 7.2 回响不是反事实比较

每个重要选项都应有事实标记、即刻结果和适当的后续内容。数量和篇幅相近是编辑检查方法，不要求所有路在同一年得到同样的事件；只对玩家已经走的路生成后续。不能生成“你看到另一个自己已经成功”的比较，也不在结局回放未选选项。

关系的另一方有自己的状态和决定，不把沟通写成“付钱就必定加关系”。人物离开或离世后应取消不合时宜的预约，转换为可以理解的后续，不用死锁或凭空复活人物。

## 7.3 建议的数据字段

| 字段 | 内容 |
| --- | --- |
| id／revision | 稳定事件编号与版本 |
| type／stage／age_window | 类型、人生阶段和年龄窗口 |
| requirements | 教育、职业、地点、人物、财务与标记要求 |
| weight／priority／cooldown／max_occurrences | 抽取、优先级、间隔和次数 |
| text／choices | 场景与 2～4 个选项 |
| choice.requirements／costs／effects | 条件、一次性／持续费用、状态变化，单位明确 |
| set_facts／schedule_echoes | 只写入已选事实，以及带窗口的回响任务 |
| time_allocation／orientation_tags | 当年的时间安排和可描述取向，不作为分数 |
| fallback／expires_when | 条件失效时如何改写、延后或取消 |
| recap_summary／person_refs | 已发生的回顾句与关联人物 |
| editorial_status／source | 原稿来源、补充建议、校对与实现状态 |

前台文案与后台效果分离：策划表保留变化方向与量级，玩家看到的选项写具体做法、当下可知的花费和时间安排，不预告精确成功率或剧透多年后的剧情。随机规则需在玩法说明中解释，不伪装为对现实的预测。

# 八、出身之外的世界环境

| 环境 | 作用 | 适配要求 |
| --- | --- | --- |
| 经济繁荣 | 机会、收入与成本一起变动 | 学生面对家庭安排；职员面对岗位；经营者面对订单和用工 |
| 经济下行 | 岗位、回款和理财承压 | 受雇角色才可能被裁员；经营者面对客流或资金链 |
| 房价周期 | 购置成本、资产估值与租住选择 | 没有买房的人也有租住、通勤等完整生活内容 |
| 市场剧烈波动 | 已有金融资产估值变化 | 有持仓才展示具体损益；没有持仓不硬弹买卖选择 |
| 公共卫生变化 | 健康风险、照护、工作与出行安排变化 | 儿童由监护安排影响；成年人可承担不同角色 |
| 技术变迁 | 某些任务减少，某些要求和机会出现 | 学习、复核、手艺、人际与转型，不只白领视角 |
| 教育／就业环境变化 | 路径条件与机会结构变化 | 按当前教育和工作状态派发不同事件 |
| 通货膨胀 | 生活费用和储蓄购买力变化 | 通过实际账单体现，不把名义余额增长当作生活改善 |

【方向确定】每个阶段至少感知 1～2 个宏观背景，不预告完整周期或最优买点。【整理建议】这是世界层的时间轴，同一世界的玩家感知同一背景；每个人按当前身份收到不同生活事件。不可为了凑次数，把同一阶段同时叠满裁员、灾害、公共卫生和市场危机。冲击并发、持续时间与恢复节奏设上限。

旧版能源分支、GDP 和城市幸福度不再作为玩家主要指标。可保留“能源成本、技术进步如何进入生活”的主题，重写成具体账单、工作与照护故事；CO₂、人口等与人物路径无关的面板与依赖不进入首版。

# 九、理财：自由配置与年度计划

【方向确定】市场随宏观周期波动，信息不完全；不标明“最佳投资”。【整理建议】保留玩家已要求的万元自由输入、部分卖出和单项清仓，同时按上传文档把每年的主动资产调整组织为一次年度计划。

| 项目 | 生命周期与限制 | 主要后果 |
| --- | --- | --- |
| 储蓄／定期 | 成年前可有个人零用钱储蓄；定期产品按年龄与资格开放 | 低波动；定期提前取用有约定条件，购买力随物价变化 |
| 国债／稳健理财 | 成年独立账户后，产品说明区分真实保障与市场风险 | 较低波动，收益与流动性约束 |
| 基金／指数 | 成年后按金额配置，可选定投计划 | 长期持有与行情相关，不承诺回本 |
| 个股 | 成年后，需理解产品与现金安排 | 较大波动、消息与信息不完整 |
| 房产 | 具备购置与偿付条件后 | 自住／租住、首付、贷款、维护与流动性 |
| 小生意／创业 | 职业与经营分支，不只是一个可随时卖出的金融仓位 | 个人时间、团队、经营账户、行业和家庭开销 |
| 借钱给亲友 | 具体人物关系事件，不是标准化理财按钮 | 借款、回款与关系分别有结果 |

## 9.1 年度计划建议规则

- 页面可随时查看；年度计划中能同时调多项资产，金额单位万元，精确到 1 元。确认前无限修改草稿，不把每点一次输入视为一次交易。

- 每年确认一次整组计划，可选择保持持仓；未确认不自动交易。持有、买入、部分卖出、单项清仓都是同一计划内的指令。

- 应急治疗、搬家、清算等事件需要变现时，可另行卖出已有资产支付已确认的费用，留下“应急变现”记录；不借此开放第二轮主动加仓。

- 【待定】定投按计划持续执行还是每年重新确认，建议持续执行并可在年度计划中停止；现金不足时跳过而不自动借款，明确记录。

- 市场和余额在后台推进后，提交前重新校验本年权限、持仓与资金。超额或负数订单不提交，保持原草稿并提示差额。

- 不提供普通借钱买股票的常驻入口；经营融资与住房贷款是独立合同和资格事件。具体贷款额度、利率与违约后果另行标定。

## 9.2 账本必须区分的东西

现金、金融资产、住房、个人债务、经营资金、经营债务和家庭资源分别存储。买房不是将房价直接减为零资产；支付首付、形成贷款、持有住房和按年偿还本金／利息是不同记录。创业投入从个人现金转到经营账户，不能同时算一次消费和一笔仍能随便取用的存款。

利率、收益、通胀、学费、医疗费与工资曲线都是待定参数。旧版“所有职业统一五十年”的数值不直接复用；先验证生命周期，再调参数，不先承诺某条路线的最终财富。

# 十、消费、工作重心与重要关系

| 消费类 | 可选内容 | 费用与时间 |
| --- | --- | --- |
| 住处 | 租住、合租、自住、换住处 | 房租／房贷、维护、通勤、空间与迁移 |
| 交通 | 公共交通、自驾 | 购置与维护、通勤时间；不凭空增加总时间 |
| 教育 | 课程、职业学习、继续深造 | 家庭或个人承担，学业／工作时间变化 |
| 医疗与保障 | 体检、保险、治疗、康复 | 一次性与持续费用；具体适用范围可见 |
| 旅行／兴趣 | 短途、远途、器材、场地、练习 | 金钱、时间与当时人物关系 |
| 聚餐／交往 | 朋友、家庭与伴侣相处 | 费用不是保证关系修复的价格 |
| 家庭支持 | 照护父母、养育孩子、协商支出 | 谁支付、谁投入时间、何时结束 |
| 身份消费 | 设备、衣着、会籍等 | 主要影响具体社交场景与维持成本，不自动提高人格或所有声誉 |
| 捐赠与帮助 | 金钱、时间或具体协作 | 能力范围内的承诺和实际经历，不积“善良积分” |

【整理建议】商店不是无限刷属性入口。同类长期承诺不重复叠加，重复活动有时间与频率上限；花钱不保证交到朋友、让亲人复活或把过去重新经历。消费记录按用途呈现，不评判“值不值”。

## 10.1 生活重心沿用交互，按年龄换内容

- 记事期：学习、玩耍、兴趣、陪伴，选择权较小；少年：学业、兴趣、朋友、休息；成年：工作、学习、关系、兴趣、休息；老年：日常、亲友、兴趣、休息、适量工作／志愿安排。

- 这些是当前时间安排，不是固定人格。切换即时显示已选状态和当前影响，不自动暂停，不偷偷改回。效果受可用时间和当前工作／家庭状态限制。

## 10.2 关系与婚育

- 把家人、早期朋友、同学、工作中认识的人、伴侣、孩子建为可追踪的人物。各人有出现与离开的年份、关系状态和共同经历；避免每次事件随便换一个“老友”。

- 恋爱、结婚、同居、分开与独身都各有内容。没有伴侣不意味着关系为空；朋友、亲人、邻居与社区可以形成支持网络。

- 想要孩子、暂时不安排和不安排孩子都保留后续生活；明确不安排后，系统不每隔几年反复劝育。只有玩家主动重谈才改写意向。

- 【整理建议】首版先保留一名孩子的成长纵深，多子女不在第一阶段。养育方式影响具体关系与安排，不把“兴趣教育”写成必然成绩差，也不把“以成绩为重”写成必然关系破裂。

- 亲人离世先基于人物时间轴与健康状态，只移除确实存在的人物；回顾引用实际发生的联系与照护，不能临时编造“每周通话四十年”。

# 十一、叙事示范：三条选择，三条各自的回响

以下是按新原则重写的示范，不是承诺这三条路径数值相同，也不是给玩家看的未选路线对比。开发时只展示实际选中的一条后续。具体数值仍待标定。

## 放在抽屉里的爱好

16 岁，课表比去年满了一些。周末的练习和下一次考试碰在了一起。

- 继续投入练习｜即时事实：你把周末留给练习，暂停了一项额外课程。熟悉的作品慢慢成形，准备考试的时间也需要重新安排。

本路径回响：23 岁，一位曾一起练习的人问你是否参加一次合作。你可以接下、只参与一部分，或先保留现有工作。

- 重新分配时间｜即时事实：你留下一周两次练习，其余时间给学校的课程。两边都继续着，进度要跟着这一周的安排调整。

本路径回响：23 岁，旧群聊里有人分享了一段新作品。你重排了自己的练习时间，可以线上一起练，也可以偶尔联系。

- 先把器材收起来｜即时事实：你把器材放进柜子，周末多了一段可以安排的时间。接下来的课业延续着，偶尔也会碰到熟悉的旋律。

本路径回响：23 岁，收拾住处时你看到了那套器材。你可以重新练习、交给需要的人，或把它继续留在抽屉里。

## 毕业后住在哪里

阶段学习结束，你要决定下一段日常从哪里开始。几个地方有不同的开销，也住着不同的人。

- 回到家乡｜即时事实：你搬回离家近的住处，和家人重新安排相处的时间。通勤和房租改变了，接下来的岗位需要慢慢了解。

本路径回响：几年后，家人商量如何照顾长辈，你在本地，可以投入时间，也可以协商其他照护安排。

- 留在熟悉的城市｜即时事实：你续租了住处，和仍在这里的朋友保持联系。原有的通勤和开销继续，每个人也开始有不同的排班。

本路径回响：几年后，朋友有人搬走，也有人留下，你们要重新安排联系。可以定期见面、少量联系或各自过一阵。

- 去另一座城市｜即时事实：你收起行李，换了一条上班的路线。新的机会需要自己联系，旧朋友的见面变成提前约好的日子。

本路径回响：几年后，家里有一件需要你参与的事，你可以回去一段、安排远程支持，或与家人协商分工。

## 是否接下更大的订单

你经营的小店收到一张订单。金额比平时高，交付时间也集中在接下来的几周。

- 接下，重新排人手｜即时事实：你确认了订单，支付一部分备料费用，并和帮手排好时间。这段日常围着交付运转，回款按约定等待。

本路径回响：订单结束后，出现关于长期合作的讨论。回款、人员和生活安排决定你是否继续扩大、维持或收缩。

- 只接能按原安排完成的部分｜即时事实：你说明了可交付的数量，对方重新确认合同。店里保持原来的排班，这次合作的范围也就定在这里。

本路径回响：之后，对方和你谈较小但持续的供货。你可以继续合作、调整条款，或为其他客人留下接单空间。

- 这次不接，继续原来的营业｜即时事实：你回了消息，保留现有客人的订单和日常排班。近期没有新增备料投入，店里的收入仍按原来的节奏到账。

本路径回响：几个月后，熟悉的客人提出不同的需求。你可以调整部分营业内容，也可以继续现有安排或留时间给生活。

# 十二、人生回顾与分享

【方向确定】终局页不授予称号、不评分、不排名、不显示遗憾清单或另一条路。分享仍然重要，但传播的内容从“我获得了什么称号”改为“这一生发生了什么”。

| 回顾部分 | 数据来自哪里 | 呈现规则 |
| --- | --- | --- |
| 这一生的基本事实 | 出生环境、开始与结束年龄、实际经历 | 标题使用人物姓名或“一生的记录”，不归类好坏 |
| 关键时间线 | 已选事实与已发生事件 | 保留原年龄和选择摘要，不列被丢弃的选项 |
| 时间分配 | 年度时间份额累计 | 显示近似比例，不编造精确工时，不比较别人 |
| 重要的人 | 人物时间轴与实际联系记录 | 只呈现确实出现的人物及关系走向 |
| 选择倾向 | 足够数量的已选取向标记 | 用描述句，不用人格称号或分数 |
| 玩家自己的一句话 | 可选输入，可留空 | 允许玩家表达个人理解，不自动评价这句话 |

# 附录 A：五阶段关键事件整合清单

本附录以用户 v0.3 的 44 个关键场景为底稿保留主题与选择。下文只使用变化方向，不把尚未验证的数值写成已定规则。“整理补充”用于补齐资格、阶段与回响；不是旧站点已经存在的事件库。所有候选分支仅供策划查看，玩家在选择后只接收到实际路径内容。

## 记事期｜6～12 岁

阶段节点：入学；第一个要好的朋友；小学毕业后的去向

### C01｜放学后的时间（入学后反复出现）

- 回家先写作业：能力↑；和同学玩的时间少了，朋友关系几乎不变

- 和同学去玩：朋友关系↑，心情↑；作业常拖到晚上，压力↑

- 去店里或田里帮忙（仅限起点为“小店里的家”“务农的家”）：家人关系↑，金钱↑；能玩的时间少

整理补充：家庭帮忙仅为适龄日常；金钱增加解释为可支配零用钱，不作为儿童正式工资。三条路径分别安排学习经历、朋友往来、家庭共同经历的后续。

### C02｜兴趣班（约 7～9 岁，家里问你要不要报）

- 报美术班：能力↑，心情↑；金钱↓，周末的时间被占去一部分

- 报体育队：健康↑，朋友关系↑；训练占满周末，偶尔受伤（健康↓）

- 不报班，自己玩：时间自由，邻里的朋友关系↑；没有系统的训练，兴趣靠自己摸索

- 金钱或条件不足时，前两项显示为“当前不可选”

整理补充：课程使用家庭预算与监护安排检查；没有参加课程的路径也有自己的兴趣探索，不能以后只拿来展示差距。

### C03｜和好朋友闹矛盾（约 8～12 岁）

- 主动去和好：朋友关系↑，心情先↓后↑；你先开了口，对方怎么回应不确定

- 等对方来找你：朋友关系暂时↓；矛盾可能自己过去，也可能拖成疏远

- 和别的同学玩：新朋友关系↑；与原来的朋友距离拉开

整理补充：为主动接触、等待与结交新友分别记录事实。朋友的回应是人物反应，不是“主动和好必定奖励”。

### C04｜班里有人被起哄（约 10～12 岁）

- 站出来说话：被起哄的同学与你的关系↑，一部分同学开始疏远你；压力↑

- 事后告诉老师：事情被处理了，但班里的气氛变了；心情↓

- 不参与也不说话：没有被牵连；这件事你记了很久，偶尔会想起

- 标记：当时的做法

整理补充：旁白不授予勇敢或冷漠称号。以后回响只提实际做过的事情，不评判未说出口的内容。

### C05｜家里问你的意见（仅限起点为“常搬家的家”“生意起伏的家”，家里将有搬家或换学校的变动）

- 想留下：朋友关系保持，熟悉的环境不变；家里的安排变复杂，父母要多费心

- 愿意走：新的城市和新的朋友，要重新适应（心情先↓后恢复）；旧朋友渐渐联系变少

- 没有意见：跟着家里的安排，少了争执；你没有参与这个决定

整理补充：保留儿童表达的范围，最终搬迁结果还要经过家庭条件；不能用六岁的一次表态任意改写所有家庭安排。

### C06｜小学毕业后的去向（必经，约 12 岁）

- 就近入学：离家近，熟悉的同学多；教育资源一般，没有额外的考试压力

- 考一所需要考试的学校：能力↑，视野更广；备考压力↑，离家更远，时间紧张

- 跟好朋友选同一所：朋友关系保持；学校与自己的成绩或兴趣可能不太匹配

- 考试类选项需要能力达到门槛

整理补充：写清实际可用的学校、课程安排和准备条件；学校不是等级奖励，“与朋友一起”也不是故意放弃更好学校的叙述。

## 少年｜13～18 岁

阶段节点：初中毕业后的分流；高中阶段的学业压力；高中毕业后的去向

### T01｜初中毕业后的分流（必经，约 15 岁）

- 继续普通教育：课程继续围绕考试与学科安排；需要满足相应条件，并投入准备时间。

- 进入职业学校：学习更具体的技能，同时进入不同的课程和后续升学路径。

- 转入职业训练或实作学习：在当前年龄允许的安排中学习一门手艺，后续再决定就业或继续学习。

整理补充：原稿“直接工作”改为转入职业训练／实作学习；正式独立就业按合适年龄与制度条件开放。各教育路径都保留后续学习机会。

### T02｜第一部手机（约 13～15 岁）

- 主要用来联系朋友：朋友关系↑；时间常被消息占去一部分

- 常用来玩游戏：心情↑，认识了一群玩伴；学业时间减少，压力↑

- 用来查资料、学东西：能力↑；和同学聊的话题有些不同

整理补充：按当前人物、年龄、资源与已发生的事实判断；为各选择记录即时结果及合适的后续，不与未选路径比较。

### T03｜一个占去大量时间的爱好（触发：记事期有兴趣标记）

- 全身心投入：相关能力持续发展，心情↑；学业时间减少，父母担心（家人关系↓）

- 控制时间，兼顾学业：两边都有进展，也都没到最深；压力↑

- 暂时放下：学业更稳；这个爱好留在记忆里，多年后可能以事件回响

整理补充：三条路径分别有延续投入、混合安排、暂时收起的回响，见第十一章示例。

### T04｜心里有了一个人（约 14～17 岁）

- 说出来（或接受对方）：伴侣关系起步，心情↑↑；分心，成绩波动，也可能受伤

- 先做朋友：关系平稳；对方可能走向别处

- 不说（或拒绝）：学业和日常不变；这份心情留在心里，之后可能回响

整理补充：双方关系决定是否开始相处，不因说出心意就强制成为伴侣；被拒或暂缓不被旁白定性。

### T05｜和父母的分歧（触发：有想做的事，与父母意见不同）

- 坚持自己的想法：家人关系↓，压力↑；这件事由你自己决定

- 听从父母：家人关系↑，少了冲突；你的想法被放在一边，以后可能再次浮现

- 表面答应，私下做自己的事：两边暂时无事；需要持续保密，压力↑

整理补充：按当前人物、年龄、资源与已发生的事实判断；为各选择记录即时结果及合适的后续，不与未选路径比较。

### T06｜一个朋友开始逃课

- 跟他一起：朋友关系↑，一起经历了新鲜事；学业受影响，老师和家长开始关注你

- 劝他回去：你们可能走得更近，也可能走远；他怎么选仍由他自己决定

- 保持距离：学业不受影响；这段友谊慢慢淡下去

整理补充：朋友有自己的选择；不能把保持距离稳定写成“学业更好的人生”。

### T07｜重要考试前夕

- 熬夜复习：成绩↑；健康↓，压力↑

- 保持作息：健康稳定，心情平稳；成绩与投入的时间相应

- 放松一晚：心情↑；这次复习的内容少了一部分

整理补充：按当前人物、年龄、资源与已发生的事实判断；为各选择记录即时结果及合适的后续，不与未选路径比较。

### T08｜暑假

- 去打零工：金钱↑，能力↑（社会经验）；休息的时间少

- 去补课：学业↑；家里的支出↑，假期少了

- 和朋友出去玩，或在家休息：心情↑，朋友关系↑；这个假期没有额外的积累

整理补充：按当前人物、年龄、资源与已发生的事实判断；为各选择记录即时结果及合适的后续，不与未选路径比较。

### T09｜高中毕业后的去向（必经，约 18 岁）

- 去外地继续学习：先确定地点与费用，再进入专业方向选择。

- 在本地继续学习：和家人、原有朋友保持较近的距离，课程与生活圈也相应安排。

- 进入工作准备路径：寻找符合年龄与资格的岗位或训练，开始规划独立收入。

- 再准备一年：延后下一阶段，重新安排学习与家庭支出；不保证结果提升。

整理补充：拆成两步，避免五选项：先选外地学习／本地学习／工作方向／继续准备，再处理专业或进一步学习的具体条件。

## 青年｜19～30 岁

阶段节点：毕业后的去向；第一份工作；离开家独立生活。亲密关系的阶段性选择不是必经，但出现概率高。

### Y01｜毕业后的去向（必经）

- 回到家乡：重新安排住处和收入来源，与家人有更多接触；岗位与学习资源按本地条件出现。

- 留在当前城市：保持部分既有联系，承担这里的日常开支；接下来寻找符合当前经历的方向。

- 去另一座城市：联系新的机会与住处，原有人际转为远距离往来；搬迁产生实际费用与时间。

- 继续学习或备考：进入下一层选择，区分研究学习、海外学习或稳定岗位备考，各自有条件和费用。

整理补充：按实际教育路径命名为“这段学习结束后”。先决定城市与下一阶段，再分读研、出国或稳定岗位备考，单次不超过四项。

### Y02｜第一份工作

- 薪资高、工作量大：金钱↑↑，能力↑；健康↓，压力↑

- 稳定、薪资一般：压力↓，空闲时间多；收入增长慢

- 与兴趣有关、不太稳定：心情↑，相关能力↑；收入不稳

整理补充：不同职位都需资格与机会；岗位选项来自当下实际可申请范围，不是每局固定任选三份保证录用的工作。

### Y03｜住在哪里

- 合租：金钱支出较少，朋友关系↑；空间和隐私有限

- 独居：自由，心情平稳；金钱↓，孤单的时候要自己消化

- 回家住：金钱支出少，家人关系↑；独立生活的机会往后推

整理补充：按当前人物、年龄、资源与已发生的事实判断；为各选择记录即时结果及合适的后续，不与未选路径比较。

### Y04｜遇到一个人（约 22～30 岁，有社交圈时触发）

- 开始交往：伴侣关系起步，心情↑；时间被分走，也需要磨合

- 保持朋友关系：关系平稳；这份感情停在这里

- 暂不考虑：时间和精力放在别处；一个人的日子更自由

整理补充：按当前人物、年龄、资源与已发生的事实判断；为各选择记录即时结果及合适的后续，不与未选路径比较。

### Y05｜异地的选择（触发：伴侣与你在不同城市）

- 为对方换城市：伴侣关系↑；原来的工作和朋友圈要放下

- 让对方来：你的生活保持原样；对方承担了迁移的成本

- 各自发展，保持异地：双方事业继续；见面少，关系需要持续经营

- 分开：各自回到自己的生活；这段关系结束

整理补充：伴侣的迁移需经共同协商，“让对方来”不是单方面按钮；分开不抹去对方与共同经历。

### Y06｜家里需要经济支持（触发：起点资源较少，或家里有变故）

- 定期寄钱回家：家人关系↑；金钱↓，自己的积累变慢

- 偶尔寄一些：家里勉强周转，自己也有积累；家人没有多说，你心里有数

- 先把重心放在自己身上：积累↑，发展更快；家里的困难要靠家里自己想办法

整理补充：按当前人物、年龄、资源与已发生的事实判断；为各选择记录即时结果及合适的后续，不与未选路径比较。

### Y07｜朋友向你借钱

- 借：借出资金；后续回款与两人的联系分别有变化

- 借一部分：你说明自己能承担的数额，对方如何回应仍有不确定性

- 不借：金钱不变；对方会作出自己的回应，之后的联系需要继续看两人的安排

整理补充：借出、部分借出和不借各有关系后续；不借不固定扣友情，借钱也不固定提高真实信任。

### Y08｜一个创业的机会（触发：能力达到门槛，有积蓄或有明确的想法）

- 辞职创业：可能获得更大的回报和自主；投入金钱，收入不稳，压力↑↑

- 保留工作，业余时间尝试：风险小；两头都占时间，健康↓

- 不做：保持现有的节奏；这个想法留在心里

- 标记：创业的选择

整理补充：只有进入独立账户后开放；经营单独建账，时间安排与家庭支出必须一起变化，不只买一个高风险仓位。

### Y09｜跳槽或转行的机会（约 25～30 岁）

- 跳槽到更大的平台：收入↑，能力↑；需要重新适应

- 留在现在的位置：熟悉，人际关系稳；成长速度放缓

- 转行从头开始：新的方向，心情↑；收入下降，资历从头积累

整理补充：按当前人物、年龄、资源与已发生的事实判断；为各选择记录即时结果及合适的后续，不与未选路径比较。

### Y10｜要不要结婚（触发：有稳定的伴侣，约 27 岁以后）

- 结婚：伴侣关系↑，家人关系↑；两个家庭的事务增多，自由度减少

- 同居但不结婚：保持现状；家人可能有不同的看法

- 暂时不谈：时间留给自己和事业；伴侣的想法需要沟通

整理补充：不结婚／暂时不谈也有后续共同生活或独立生活内容。登记选择与是否养育分开。

## 中年｜31～55 岁

阶段节点：成家与否的阶段状态；事业平台期；父母逐渐年迈；身体的变化

### M01｜要不要孩子（触发：有伴侣，约 28～40 岁）

- 要：家人关系↑↑，生活被重新安排；金钱↓，时间减少，压力↑

- 暂时不要：保持现有的节奏；这个决定可能需要反复面对

- 不要：时间和金钱更自由；身边朋友的生活节奏与你不同

整理补充：虽然列在中年主题池，28～40 岁的窗口可跨青年与中年；不要按阶段分类误锁 28～30 岁。明确不要后不再反复自动询问。

### M02｜孩子的教育方向（触发：有孩子）

- 围绕学业安排时间：增加相关学习与准备，也需要共同安排休息、兴趣与相处。

- 围绕兴趣安排时间：让孩子深入具体兴趣，同时商量基础学习与以后方向。

- 让孩子参与决定：共同明确预算与边界，保留调整空间；家长不代替孩子选定全部日常。

整理补充：教育方式不与某一固定好坏结果绑定。孩子有兴趣、压力与自己的反应；修改原稿“兴趣必然升学更窄”的绝对表达。

### M03｜父母需要照顾（触发：父母年龄较大或健康下降）

- 接来同住：家人关系↑，照顾及时；日常生活被改变，压力↑

- 请人照顾，定期探望：金钱↓，生活基本保持原样；见面的时间有限

- 自己回去照顾一段时间：陪伴的时间多；工作和收入受影响

- 条件不足时，部分选项显示为“当前不可选”

整理补充：照护以父母是否存在、年龄、健康和支持网络为条件；不能只按玩家到了中年就默认所有父母同时生病。

### M04｜事业的平台期

- 争取管理岗位：声誉↑，收入↑；工作内容变成带人，压力↑

- 继续深耕专业：能力↑；收入和职位的增长有限

- 转行：新的开始，心情↑；收入和资历从头积累

- 创业：参见 4.4 的创业机会，条件更宽，代价也更具体（家庭支出）

整理补充：对应受雇、专业、自由职业与经营角色分别改写；没有公司管理序列的人不出现“争取公司管理岗”。

### M05｜公司裁员（可由宏观事件联动触发）

- 接受补偿离开：金钱暂时↑；之后的收入需要重新找

- 争取留下：收入保持；压力↑，工作氛围有变化

- 主动去找新机会：不确定性↑；可能获得更合适的位置，也可能空档较长

整理补充：仅在受雇岗位真实面临缩减且尚可协商时出现。已经执行解聘后不能再提供“争取留下”的假选项；经营者另用订单／客流／周转事件。

### M06｜婚姻中的矛盾（触发：伴侣关系偏低）

- 认真沟通：关系可能↑，也可能暴露更多分歧；心情先↓后可能好转

- 保持现状，各过各的：日常平稳；矛盾没有解决，关系逐渐变淡

- 分开一段时间：各自有空间；关系走向不确定

- 离婚：关系结束，生活重组；金钱↓，心情↓，自由度↑

整理补充：恋爱、同居和登记关系使用对应措辞；离婚／分开支出要说明，不沿用固定神秘扣款。孩子与后续照护仍在。

### M07｜一直想做的事（触发：约 40～50 岁，心情偏低或压力偏高）

- 去做（学一门东西、换一种生活、出一趟远门）：心情↑↑；时间和金钱被占用，家人需要理解

- 推迟到以后：现有的生活保持稳定；这件事可能一直都在

- 放下：心里腾出了位置；偶尔会想起

整理补充：按当前人物、年龄、资源与已发生的事实判断；为各选择记录即时结果及合适的后续，不与未选路径比较。

### M08｜朋友推荐一个投资项目

- 投入较多：可能有回报，也可能亏损（见 6.3）；金钱与朋友关系联动

- 小额参与：风险小；收益也有限

- 不参与：金钱稳定；与对方的关系保持原样

整理补充：资产计划与朋友关系分别记录；不参与不等于失去朋友。项目条件、成本与信息不确定性先说明。

### M09｜买房或换住处

- 买房：居住的稳定感↑，还贷压力↑；灵活性下降

- 继续租：灵活，资金可以做别的事；居住的不确定感

- 回老家：生活成本低，家人关系↑；职业机会变少

整理补充：购房需现金、贷款和持续偿付检查；租住同样有可持续的居住故事。

### M10｜一位老朋友的消息（触发：多年未联系）

- 主动联系，见面：朋友关系↑，回忆被唤起；两个人都已经变了

- 简单问候：保持淡淡的联系

- 不回应：生活照旧

整理补充：按当前人物、年龄、资源与已发生的事实判断；为各选择记录即时结果及合适的后续，不与未选路径比较。

### M11｜身体发出的信号（触发：压力高，或 40 岁以后健康下降）

- 去体检并调整生活：健康↑；占用时间和金钱

- 靠药物缓解，继续工作：短期不受影响；健康风险累积

- 不处理：保持现有的节奏；健康继续下降，可能触发重病事件（见 5.4）

整理补充：按当前人物、年龄、资源与已发生的事实判断；为各选择记录即时结果及合适的后续，不与未选路径比较。

## 老年｜56 岁以后

阶段节点：退休；亲友的离去；身体的衰退；生命的最后阶段

### O01｜退休（必经，约 56～65 岁）

- 完全退休：时间↑，压力↓；收入变少，日常的节奏需要重建

- 返聘或做兼职：声誉保持，收入↑；仍被工作占用时间

- 开始一件新的事：心情↑，能力↑；体力和资金有限

- 做志愿者或帮忙带孙辈：关系↑，被需要；自由的时间少

整理补充：退休是从现有工作安排转变，不让尚未就业或早已退出的人再次被强制退休；56 岁仅是阶段参考。

### O02｜居住方式（约 65 岁以后）

- 与子女同住：家人关系↑，有人照应；生活习惯需要磨合

- 自己住：自由，心情平稳；有事时靠自己和邻居

- 去养老机构：照护↑，同龄人多；金钱↓，离开原来的家

- 回老家：熟悉的环境；医疗和照应的条件不同

整理补充：与子女同住需确有子女且对方同意。独身或无子女路线提供友邻支持与照护方式，不显示残缺的人生。

### O03｜财产的安排

- 留给家人：家人关系↑；自己的花销收紧

- 部分捐出：声誉↑；留给家人的减少

- 自己花掉：生活质量↑；留下的少

整理补充：先区分已负担的债务、自己未来照护预算与可安排资产。捐赠不自动带来道德声誉，关系后果不固定。

### O04｜一位多年未见的老朋友

- 约一次见面：朋友关系↑，聊起很多往事；体力上有些吃力

- 写信或打电话：保持联系；见面的机会少

- 保持现状：生活照旧

整理补充：按当前人物、年龄、资源与已发生的事实判断；为各选择记录即时结果及合适的后续，不与未选路径比较。

### O05｜伴侣或老友离世（触发：伴侣或朋友年龄较大）

- 与家人在一起，说起他们：家人关系↑，悲伤逐渐缓和

- 保持日常的生活：生活继续；独处时心情↓

- 参加社区活动：新的关系↑；需要主动走出去

整理补充：只对实际人物生成离世事件；不同处理方式不规定悲伤必须在固定年数里恢复。

### O06｜想对某个人说的话（触发：有未解决的关系标记）

- 当面说：关系可能缓和，也可能没有回应；这件事有了去处

- 写下来：想法被整理清楚；不一定被对方看到

- 不说：关系保持原样

整理补充：按当前人物、年龄、资源与已发生的事实判断；为各选择记录即时结果及合适的后续，不与未选路径比较。

### O07｜健康的决定（触发：慢性病或重病）

- 选择可以获得的积极治疗：投入费用、时间与照护，恢复程度仍有不确定性。

- 选择维持与缓解的照护：按既定计划生活和复诊，身体状态继续变化。

- 不再增加治疗安排：确认身体与照护事实，把剩下的时间按自己的想法安排，不据此判断关系深浅。

整理补充：呈现可获得的照护方式与未知结果；不把放下治疗等同于“更爱家人”。家人关系也不由该选择机械大幅加分。

### O08｜最后的一天（触发：健康很低，终局之前）

- 与此时仍在的重要的人待在一起。

- 一个人安静地待着。

- 在身体和条件允许时，去一个自己想去的地方。

- 维持平常的安排。

整理补充：终局叙事，不改变任何状态值。按还在的人与可达地点适配；这条不强制“每选都有得失”。
