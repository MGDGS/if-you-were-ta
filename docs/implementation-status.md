# 实现状态 · 完整可玩版 v2

2026-10-30：从6岁到生命终点的连续版本，取代只到18岁的S1入口。数值、岗位、经济、医疗和制度仍是简化的游戏模拟，不是真实预测。

## 当前可玩闭环

- 8个出身中生成3个，至少含两档家庭资源；姓名随机、不可编辑。
- 童年、少年、青年、中年、老年逐年推进；19岁后继续，不在18岁截断。
- 普通教育／职业训练，成年继续学习、求职、接单、经营、公共服务与任期职责；资格和实际状态影响事件。
- 个人现金／欠款、理财、住房／贷款、经营周转金／欠款、公共预算分开；年度收入、税、费用、家庭支出、利息与养老金记账。
- 每年一次多资产理财计划：万元自由输入、部分卖出、单项清仓；统一校验和结算。必要时应急变现另记。
- 相处、登记／同居／独身、分开和新的相处；选择养育后可准备生育或申请收养；一名孩子成长与实际支出。
- 父母照护、个人身体、亲友离世、退休、居住与财务安排、最后一段日常，最后进入人生回顾。
- 早期联系／兴趣、迁居距离、实际经营年数、住房持续负担和成年联系等，影响多年后的实际条件。
- 宏观经济阶段与市场、技术、公共卫生和学习要求变化；不同身份使用不同日常，经营者不被公司裁员。
- 自动保存当前人生与本设备历史回顾。新版不提供数据导出／导入按钮；PNG与精选片段分享保留，不发送完整存档。
- S1进行中或18岁记录可在新入口自动接入；旧S1页面s1.html和旧成人版old.html仍保留。访客分享不覆盖自己的存档。

## 表达与范围

没有称号、人生总分、成就排行、遗憾清单或未选路线比较。生命收束有游戏规则与不确定性，最多到100岁；死亡不是用户选择的道德评分。

当前是一名孩子、简化资格／家庭资产／贷款／企业和公共事务模型，没有真实房产市场、多子女或婚姻财产法律模拟。学校、岗位和医学规则不能当作现实建议。完整可玩指人生可连续走到终点，不代表每个策划示例都已有独立精细剧本。

## 事件弹窗等待与临时关闭（2026-10-30）

重大事件触发时立即暂停时间，等待已打开的资料窗口关闭后再弹出，不替换当前窗口或丢失金额草稿。事件支持“稍后决定”和Esc临时关闭；暂停期间可自由查看资料窗口，关闭资料也不会自动重弹已暂缓的事件。通过“继续决定”重新打开，完成选择后继续时间。尚未决定的事件保留在原有存档中，刷新后仍可继续决定；临时子选项草稿在本次页面会话中保留。
