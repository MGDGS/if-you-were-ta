# 《再来一次》下一步可玩切片策划文档

S1 · v1.0｜6～18 岁与成年去向｜2026 年 10 月 30 日｜待制作规格，不是已实现版本

依据《游戏进程与事件策划案》最后一节：先制作 6～18 岁到成年过渡，再用最小闭环延伸至中年与老年。本稿只定义第一个可玩切片的具体内容、数据、节奏和验收；不提前扩成完整人生，也不修改现有站点。

# 一、这一份切片要验证什么

- 在不靠成年工资、婚育和结局称号的情况下，童年与少年日常是否让玩家愿意读、愿意选。

- 三个出身是否产生实际不同的可行安排，又不会让其中一个起点在所有方面占优。

- 8 岁左右的选择与随后真实联系，能否在 16 岁影响朋友愿意参与的安排；7～17 岁的实际兴趣投入，能否在 18 岁改变某项尝试的准备条件。

- 18 岁离开当前学习阶段时，能否把学习、训练、收入准备和家庭支持交代清楚，而不是突然成为老板或进入统一大学剧本。

- 事件、状态、时间安排与存档是否能组成可扩展的闭环。

体验终点是“18 岁，下一段生活的安排已确定”。这是切片完成，不是角色死亡，也不是最终人生回顾。预计首轮体验约 8～15 分钟，实际以阅读与测试为准；不强制要求玩家达到某个时长。

| 出身 | 玩家看到 | 后台实验设置 | 限定内容 |
| --- | --- | --- | --- |
| 老街坊里的家 | 放学的路上有人叫得出你的名字，门口常放着邻居借来的东西。 | 年度可商量的课外活动支持1800元；个人初始零用钱200元 | 邻里活动与熟人往来 |

# 五、实验状态与结算

| 状态 | 起始／范围 | S1处理 |
| --- | --- | --- |
| 健康 | 80／0～100 | 运动、休息和小病影响；本切片不安排致命疾病或死亡分支 |
| 心情 | 60／0～100 | 随事件小幅变化，年度向60回归：本年值＋(60－本年值)×0.1 |
| 能力 | 30／0～100 | 每学年基本成长+1，相关安排可增加；总值不等于专业资格 |
| 关系 | 分具体人物 | 家人初始60；朋友在6岁相遇时50，没有关系总分 |
| 声誉 | 学校／社区范围初始20 | 仅影响本阶段是否有人熟悉你的经历，不用于成年权力 |
| 压力 | 后台初始20／0～100 | 以睡眠和叙事反馈，不常驻；年度自然缓解3点 |
| 个人现金 | 200元 | 年度零用钱240元，统一在年末入账；具体消费即时扣 |
| 家庭活动支持 | 600／1200／1800元 | 仅用于本年度课程等约定活动；不借款，不累计成资产 |
| 兴趣记录 | 分类独立 | 记录绘画、运动或自选活动的实际投入年数／中断，不用能力总值替代 |
| 时间安排 | 每年100份 | 课程与必要生活65，剩余35在学习、兴趣、朋友、家庭和休息之间分配 |

阶段只有一个年度安排生效，重复点击不重复加属性。年末依次：确认安排和费用 → 累计该年真实投入及联系 → 结算小幅状态变化和零用钱 → 保存本年记录 → 年龄+1。18岁结束时不再执行19岁结算。

时间默认份额建议：学习重心为学习15／兴趣5／朋友5／家庭5／休息5；兴趣重心为5／15／5／5／5；朋友重心为5／5／15／5／5；休息重心为5／5／5／5／15。S1只做四种，每次切换即时高亮，下次年末采用当时确认的安排。主要选择造成的持续约定先占用时间，再按余量分配，不让总额超过100。

数值量级建议：一般事件状态变化±1～3，少量阶段转折±4；不因一次童年选择扣去几十点健康。费用检查使用对应账户，扣款同时产生防重复标记。个人现金不足仍有无额外支出的可行选项。

# 六、11张基础关键事件卡

卡片中即时数值是供原型验证的建议，不代表行为价值。后续实际实施时，费用、状态、时间与标记按同一条事务落盘。未写明持续投入的选择，不自动持续累计多年能力。

## S01｜放学后的时间

年龄：6岁。场景：你记住了回家的路，同学在校门口招呼你一起走。

- A．先完成作业｜能力+2，写下这一年的学习安排。记录：study_priority；不直接生成长期学业优势。

- B．和同学玩一会｜与这名朋友建立一次共同经历，心情+2。记录：friend_id固定；shared_activity_years首次记录。

- C．在家参与一件小事｜家人关系+2；按出身写柜台、田边或邻里小事。记录：family_participation；不支付正式工资。

## S02｜周末的兴趣

年龄：7岁。场景：家里问你想怎样安排一段固定的周末时间。

- A．参加绘画活动｜家庭支持扣900元／年；选择本年练习安排。记录：支持不足时不可选，明确差额；以后可以调整。

- B．参加体育活动｜家庭支持扣500元／年；形成运动安排。记录：消耗兴趣时间；年度健康+1，不累积绘画作品。

- C．自己摸索｜不使用家庭课程支持；选择绘画自练、其他活动或自由玩耍的轻量子项。记录：子项只定活动标签，不再强制弹一个主线；自练需真实投入。

## S03｜和朋友争执之后

年龄：8岁。场景：你们在一件小事上停住了，第二天谁也没有先说话。

- A．主动去说一说｜发起沟通；用固定种子决定对方当下是否愿意回应。记录：记录接触而非直接给修复成功。

- B．先等一阵｜暂不联系，当前关系变化小幅为负。记录：后续仍能联系，不锁死朋友。

- C．先与别的同学来往｜新增一段同学经历，原朋友当年联系较少。记录：不删除原人物；后续同一朋友仍可能来往。

## S04｜课间的起哄

年龄：10岁。场景：有人在课间起哄，一位同学没有接话。

- A．当场说话｜记录与现场人物的互动，压力+2。记录：class_response=spoke；不授予勇敢标签。

- B．之后找老师｜老师介入，记录后续班级相处。记录：class_response=told_teacher；反应根据实际场景。

- C．离开现场｜不加入现场争论，保留知道此事的事实。记录：class_response=left；不授予冷漠标签。

## S05｜家里的安排有变化

年龄：11岁。场景：小店客流或农产品收购条件变化，家里商量一段时间的安排。

限定：仅小店与务农家庭。老街坊家庭同年使用邻里日常，不补一个无关困难。

- A．每周帮一小段｜占用家庭参与时间5份；家人关系+2。记录：仅适龄小事；减少其他自由时间，不承担家庭全部收入。

- B．维持原有安排｜按现有时间继续，家庭由成人调整。记录：不自动扣亲情；不改变活动支持。

- C．商量减少一项开销｜实际停止一项尚未支付的课程或消费，重新分配时间。记录：不得退回已经发生的费用；没有此类开销时不展示该选项。

## S06｜怎样继续联系

年龄：11岁。场景：你和8岁时的那位朋友最近不常碰面，你们谈起接下来怎样来往。

- A．约一个固定时段｜每年朋友时间至少5份，计划持续到玩家调整。记录：年末才累计实际联系；不是点击就得到几年信任。

- B．偶尔有事再联系｜没有固定约定，按实际日常记录偶尔来往。记录：不承诺长期合作支持。

- C．暂不增加联系安排｜保持自己的现有生活，后续不自动造固定来往。记录：不立即删除友谊，也不凭空制造绝交。

## S07｜下一阶段的学校

年龄：12岁。场景：你看着下一阶段学校的安排，也听家里说起路上的时间。

- A．去附近学校｜使用常规入学安排；通勤较短。记录：所有出身保留可行路径。

- B．准备另一所学校｜需能力≥35且有准备时间；结果由条件与种子决定。记录：未获所申请机会回到可入学安排，不判失败结局。

- C．优先考虑熟悉同学｜只在实际可入学校中选择共同生活圈。记录：不能突破资格或指定朋友必定同校。

## S08｜重新安排兴趣时间

年龄：13岁。场景：新课程占了更多时间，周末安排需要重新看一遍。

- A．保留固定练习｜每年兴趣时间至少15份，按课程或自练方式执行。记录：实际完成年度才积累训练年数。

- B．留少量时间继续｜兴趣时间5份，保留较低强度积累。记录：不得按专业训练同等计数。

- C．先暂停｜停止本期课程与后续练习积累，释放时段。记录：已有作品不删除；以后可以重新选择兴趣重心。

## S09｜教育方向

年龄：15岁。场景：当前阶段结束，几条不同的学习安排需要你确认。

- A．继续普通教育｜需能力≥40；进入相应课程。记录：不足时提示准备条件，仍保留其他可行安排。

- B．进入职业学校｜接触具体技能课程，基础费用由切片家庭保障承担。记录：不在回顾里排列高低；后续可继续学习。

- C．进入适龄实作训练｜在虚构制度和年龄允许的训练中实践。记录：不是独立正式就业；不生成成年全职工资。

## S10｜评估前的几天

年龄：17岁。场景：你还有一部分内容想再看。普通课程是评估，职业路径是实际技能展示。

- A．多用一晚准备｜本次准备记录+1，健康-1、压力+2。记录：不保证考核结果。

- B．保持原来的作息｜按已完成内容参与，状态不额外加减。记录：不把保持作息写成更优。

- C．留一晚休息｜心情+2，本次不新增准备记录。记录：不是故意判低成绩。

## S11｜18岁，下一段怎样安排

年龄：18岁。场景：这段学习告一段落，你需要为接下来的日常确定一个方向。

- A．在本地继续学习｜检查当前路径可进入的课程；记录已准备事项。记录：成人账户状态尚未独立，已知支出与家庭支持分别说明。

- B．去外地继续学习｜需实际课程资格与家庭协商结果，不能只凭现金保证入学。记录：记录迁居计划，专业细选留给下一阶段。

- C．准备进入工作路径｜按资格寻找训练或岗位，并建立下一阶段预算计划。记录：记录planned_work，不立刻领取一年工资。

- D．再准备一段时间｜明确准备内容和下一阶段费用来源。记录：不保证提高结果；切片只完成安排，不多跳一年。

S02、S08确定活动内容与投入，生活重心可在之后调整；没有完成年度练习不增加练习年数。S06的固定联系也需实际时间，不把承诺直接当作已实现。S11允许按资格隐藏不可适用分支，但须至少有一条可行的下一阶段准备路线。

# 七、两张真正的多年回响卡

## R01｜朋友愿意怎样一起做

起因：S03的处理与此后真实往来。中间：S06以及11～15岁年度记录。触发窗口：16岁，学校或社区有一个可参与的合作活动；仍是原来那位朋友，而且存在实际联系。

实验判定：11～15岁中至少3年有实际联系，且发生至少一次双方完成的共同安排，才产生“愿意商量共同承担”的版本。关系总值不能单独替代记录。只有偶尔联系则是较轻的邀请；多年没有来往时，不突然获得同等信任支持，可出现普通活动信息，但不算R01已触发。

场景：活动需要两个人协调一段时间。过去相处形成的信任，影响对方愿意承担的范围和沟通方式。

- 共同承担：双方同意后各分具体任务，占用本年朋友／活动时间，可能改变其他安排。

- 只参与一部分：明确自己能做的任务与时间，对方仍可另找人协作。

- 不增加本年安排：当前日程保持，不自动扣友谊，对方继续自己的活动。

实际作用：过去选择影响了当下可协商的协作范围，不只是出现一句“你想起8岁的朋友”。保存起因、实际联系年份、共同安排和本次反应。

## R02｜可以尝试哪一部分

起因：S02、S08与7～17岁实际兴趣投入。触发：18岁一次与实际兴趣相关的学校／社区展示或短期尝试；不得发出需要成年专业资格的正式工作邀请。

绘画示例：固定投入年≥4且已有≥3次实际作品记录，可带现有材料参与完整尝试；有≥2年低强度投入或旧作品，可参与较小任务或先整理材料；只在7岁点过课程而以后没有投入，不给同等条件。运动兴趣改写成相应的训练与协作任务，不能发来绘画邀约。

- 按现有积累参与：实际检查材料与投入，占用当前准备时间，不保证录取或报酬。

- 先完成一项小范围准备：补足明确缺项，支出与时间即时记，后续是否能参与取决于窗口。

- 不参与这次安排：保持当前准备方向，已有兴趣经历仍保留，不写遗憾。

实际作用：童年与少年形成的材料和能力改变当下能做的事与准备成本。没有任何相关积累时，不给“暂停带来隐藏天赋”的补偿事件；普通18岁日常继续即可。

## 7.1 因果记录格式与验证

| 字段 | S1最小内容 |
| --- | --- |
| source_choices | 已发生的S03／S06或S02／S08及选择年龄 |
| annual_evidence | 真实联系、作品、训练与中断年份 |
| current_conditions | 人物仍在、年龄、当前学校或活动场景 |
| realized_effect | 此次协商范围／资格／准备成本的具体变化 |
| resolved_id | R01或R02一次性结算编号，不重复执行 |
| status | 尚未满足／候选／已发生／不再适用，未发生不报错 |

删除持续来往或练习证据后，不能仍出现同一资格和协商范围；只改文案、不改任何当前条件，不算通过回响验收。反过来，改变后续安排后必须更新判断，不能只看童年曾经选择过什么。

# 八、26条日常槽位的制作内容

每个年龄至少准备下列两条主文案，再补必要条件变体。它们用于构成实际可读的节奏，不是随机抽几十句填年龄。变化为低量级，叙述和账本应一致。

| 年龄 | 第一条 | 第二条 |
| --- | --- | --- |
| 6 | 你记住了教室旁边的楼梯。 | 晚饭后，有人问起今天认识了谁。 |
| 7 | 介绍活动的纸放在桌边。 | 本年选择的活动开始占据一小段周末。 |
| 8 | 课间，你们又在同一条走廊上碰面。 | 那次争执后，彼此的回应实际发生了。 |
| 9 | 你把自己做的一件东西收进抽屉。 | 休息的一天，你和家人按平常的时间吃饭。 |
| 10 | 教室里的一段交谈忽然停住。 | 几天后，班里的相处有了一点具体变化。 |
| 11 | 小店客流／农场收购条件变化；老街坊改为邻里往来。 | 固定联系、偶尔来往或各自安排，按真实选择写。 |
| 12 | 你整理了上一阶段留下的书和用品。 | 新的通勤路线和实际入学安排逐渐确定。 |
| 13 | 新的课程表贴在桌旁。 | 本年练习、暂停或其他兴趣，留下实际投入记录。 |
| 14 | 一种熟悉的活动又出现了一次。 | 你们各自的安排开始有不同的时间。 |
| 15 | 学校和家里谈起下一阶段。 | 普通课程、职业课程或训练的材料已经放好。 |
| 16 | 当前路径的一次日常合作或学习任务。 | 假期的一个下午，按本年重心安排过去。 |
| 17 | 评估或技能展示前，你看过已经完成的内容。 | 参与之后，按实际条件呈现结果，不宣布人生高低。 |
| 18 | 这一阶段的课程或训练告一段落。 | 你把下一阶段要用的几样东西放在一起。 |

变体必查：小店／务农／街坊；有无固定课程；原朋友是否联系；学校是否相同；普通教育／职业学校／实作训练；绘画／运动／其他兴趣。年度真实练习、作品或共同活动必须由实际发生的记录产生，不能仅因某句日常文案提到了就重复计数。

# 九、18岁交接页，不是假结局

- 标题：“18岁，下一段生活从这里开始”。显示实际人物、已经决定的去向与需要准备的事项，不出现“你的一生结束了”。

- 列本段关键经历、真实关系、已发生的回响与当前状态。没有出现的R01／R02不显示问号、进度条或遗憾清单。

- “保存这段进度”“导出测试存档”“重新开始体验”“返回首页”。后续尚未开发时不放一个可以点击却无反应的继续按钮；用文字说明下一阶段尚未开放。

- 存档标识slice_complete，角色仍存活。下一阶段以后读取这个状态从19岁继续，而不是把它当作完整人生终局。

- 如需分享，仅分享已经发生的片段，标题注明6～18岁试玩记录，不生成虚假的最终寿命、人生称号或全生涯时间比例。

# 十、实现顺序与交付物

| 步骤 | 交付 | 必须能验证 |
| --- | --- | --- |

建议交付：切片说明README、事件与日常数据、人物和家庭实例数据、两条回响规则、最小状态格式、存档样例、测试结果与已知限制。它们应使用新版本路径，不覆盖旧的site/成人引擎。该建议是后续开发安排，本文件没有开始实现。

# 十一、验收路线与判断标准

| 路线 | 操作要点 | 预期 |
| --- | --- | --- |
| A｜街坊＋持续兴趣 | 参与活动、持续投入、实际交往 | 存在满足条件的R01和R02版本 |
| B｜务农＋自练 | 绘画课程支持不足，选择无收费自练并真实投入 | 费用不会造儿童欠款；实际自练仍可形成不同程度条件 |
| C｜小店＋暂停 | 开始课程后暂停，按家庭变化重排时间 | 停止新增练习证据；不能假称持续十年训练 |
| D｜普通教育未达条件 | 能力不足时查看学校与训练选项 | 至少有一条可行安排，不删除角色或强迫重开 |
| E｜职业学习 | 15岁选择职业学校，完成对应技能展示 | 17／18岁不出现统一高考和大学毕业 |
| F｜少来往 | 8岁暂不联系、11岁无固定约定 | 16岁不凭空得到同等信任；不扣成“差人生” |
| G｜重载与重复提交 | 在待选、支付、回响和18岁交接时刷新 | 相同节点只结算一次；草稿、余额与人物保持 |
| H｜中途改变重心 | 持续练习后更改、再恢复 | 按实际年度统计，不按最早标记锁定 |
| I｜未触发回响 | 条件不满足直接继续 | 主线完整，不用回忆冒充回响补数量 |
| J｜移动端 | 看旧记录、打开面板、点选和返回后台 | 阅读不跳位；信息不暂停、主选择暂停、选后立刻高亮 |

每个出身至少覆盖两种教育路径与两种兴趣持续方式；建议用固定种子跑组合，核对年龄、可选项、金钱、人物、证据和防重复，不评定哪条路线活得更好。人工试玩重点问：你知道自己为什么能选或不能选吗？能否看懂多年后的条件与早年选择有什么关系？不是问是否获得最高数值。

# 十二、完成界线与下一阶段

S1完成的标准：三个出身能从6岁走到18岁交接；至少两条不同生活路线读起来连贯；能通过持续投入及真实来往观察两种多年影响；改变中间条件时回响随之改变；无死锁、重复结算与错误身份文案。没有接完所有分支不代表人生不完整，但制作验收必须检查所有卡片。

下一阶段先做19～30岁的独立账户、第一份收入与工作／继续学习路径，接住S11，而不是直接扩展所有成年职业。之后再以少量真实节点连接中年、退休与回顾，验证一生的闭环。完整投资、婚育和复杂经营在闭环稳定后加入。

本切片参数为实验值；活动支持、成长速度、窗口、时间份额和阅读时长应依据试玩调整，不把本文件当作现实教育、职业和财务制度。两个线上站点及已归档文档版本在本次操作中保持不变。
